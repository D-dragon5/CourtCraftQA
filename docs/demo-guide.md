# CourtCraftQA 现场演示流程

这份流程用于约 8–10 分钟的现场演示：选择一个回合，结合视频、标注图和 Excel 记录逐题核对，再查看具体改动并保存。演示使用独立副本，正式标注保持原样。时间较紧时可使用文末的 3 分钟版。

## 演示前准备

建议提前一天完成一次完整彩排，明天开场前再确认以下事项。

1. 在项目目录打开终端，用一个可用的回合准备演示副本。以下以本地数据中的 C251 为例，替换命令里的源回合目录：

   ```powershell
   python scripts/prepare_demo.py "D:\basketball-data\C251"
   python token_viewer.py --config demo-config.json
   ```

2. 打开 `http://127.0.0.1:5016`。在这个地址完成全部保存和清理演示；检查配置使用 `demo-data`，避免在日常标注页面操作。
3. 准备脚本默认创建下列四个独立回合。已有演示目录和配置均不会被覆盖；重复彩排可使用新的 `--output demo-data-rehearsal --config demo-rehearsal.local.json`，并用这份新配置启动。默认演示也可双击 `start-demo.bat` 启动、`stop-demo.bat` 关闭。

   | 演示回合 | 初始状态 | 展示用途 |
   | --- | --- | --- |
   | `01-C251-edit` | 有源 `qa.json`，没有新版 | 浏览、编辑、对照、跳题和首次保存 |
   | `02-C251-clean` | 有源 `qa.json`，没有新版 | 无改动时不生成 `qa-new.json` |
   | `03-C251-duplicate` | 新版与源件内容相同 | 重复新版的清理提示和备份 |
   | `04-C251-saved` | 新版中有“演示旧版修改” | 恢复源后先核对磁盘旧版差异 |

   使用其他源回合时，名称中的 `C251` 会替换为源文件夹名称，题目内容和数量以页面显示为准。

4. 逐个打开四个回合，确认视频能播放、标注图片能显示。若出现重复新版提示，准备阶段先按 Esc 返回，保留演示所需的初始状态。人物参考所需的 `source_PL_label.xlsx` 应与视频和源 JSON 在同一回合目录。
5. 浏览器恢复常用缩放比例；尽量给页面一个完整窗口。关闭会遮挡页面的下载提示、输入法候选框和通知。英文快捷键演示时切到英文输入，数字小键盘先检查 Num Lock 状态。
6. 把 `demo-data` 和演示备份目录放在文件管理器中备用，便于最后展示保存结果。仓库只提供代码和准备脚本，实际比赛素材从本机选择。

现场使用本机页面即可。服务器运行时也可以通过本机转发地址观看和操作；本机数据与服务器副本分别保存，演示时始终使用事先准备好的同一份副本。

## 8–10 分钟完整演示

### 1 选择回合与介绍布局 约 50 秒

**回合：** `01-C251-edit`。

**操作顺序：**

1. 鼠标移到左边缘，展开文件列表，选择 `01-C251-edit`。
2. 鼠标移开，让文件列表收起；再展开并点一次“固定”，展示两种状态，随后取消固定。
3. 指向左侧视频、下方标注图、右侧当前问题与答案。

**预期看到：** 文件列表平时隐藏，主页面保留视频、图和当前问答。C251 示例共 21 题，题目按动作、战术、结果和复盘排列。

**可以这样说：**

> 我们按回合逐题核对。视频、标注图和当前问答放在同一屏，切题时不用在几份文件之间来回找。文件列表需要时再展开。

### 2 播放与定位画面 约 60 秒

**回合和题目：** `01-C251-edit`，动作阶段第 1 题。

**操作顺序：**

1. 按空格播放，再按空格暂停。
2. 依次按 `A`、`J`、`D`，展示跳到当前阶段截断点前 2 秒、截断点、后 2 秒。每次跳转后视频会直接播放；演示后用空格暂停。
3. 按 `←`、`→`，各微调 0.3 秒；按 `↓`、`↑`，展示音量变化。
4. 按 `X` 放大当前标注图，按 `Esc` 返回。

**预期看到：** 阶段时间点定位后直接播放，微调从当前播放位置前后移动。方向键也兼容数字小键盘 `4 / 6 / 2 / 8`，按钮上标有对应快捷键。

**可以这样说：**

> 先看截断点附近的动作，再用 0.3 秒微调检查接球、站位和出手的瞬间。图里看不清的地方可以直接放大。

### 3 核对选择题与逐题前进 约 60 秒

**回合和题目：** `01-C251-edit`，动作阶段第 1–3 题。

**操作顺序：**

1. 指出第 1 题标有“原答案”的选项，点击另一个选项，展示直接点选。
2. 再点击带“原答案”的选项，精确恢复原值。
3. 按 `Enter` 前进，按 `Q` 返回；再用 `Backspace` 展示另一种上一题方式。操作时让焦点离开文本输入框。
4. 用 `Enter` 到动作第 3 题，查看答案中的 `Jalen Duren` 及其下方人物记录。需要时点“展开记录”。

**预期看到：** 选择题可直接点选；选回原答案后不留下该项改动。直接下一题也会沿用原值。人物记录显示 Excel 原始时间标记、动作和表格行号。没有匹配人物参考时，底部显示小龙图标和 `dddlong`。

**可以这样说：**

> 选择题点击即可核对，沿用原答案或直接下一题都可以。遇到人物名称，下面会把同目录 Excel 中的相关记录贴出来，方便回到原始标注判断。

### 4 编辑一条文字答案 约 60 秒

**回合和题目：** `01-C251-edit`，动作阶段第 4 题。

**操作顺序：**

1. 到动作第 4 题，单按一次 `Shift` 进入答案编辑。
2. 在演示副本中，把“高位附近”改为“内侧接应区”，删除“同时”，并在末尾加上“需结合接球瞬间核对。”。这些文字仅用于展示修改操作，战术内容应结合视频判断。
3. 在新增内容附近输入一个空格和回车，随后单按 `Shift` 退出编辑，展示自动清除修改答案里的空格和换行。
4. 再进入编辑状态，按 `Shift + J` 展示编辑时调用截断点快捷键，再退出编辑并暂停视频。

**预期看到：** 编辑时答案框高亮，旁边提示“编辑答案状态，使用快捷键需摁住 Shift”。普通键用于输入；需要操作视频或切题时按住 Shift 组合使用。

**可以这样说：**

> 单按 Shift 就能切换编辑状态。框高亮时可以安心输入，快捷键需要加 Shift；结束编辑后会自动清除这条修改答案里的空格和回车。

### 5 查看完整源 JSON 与复盘题 约 60 秒

**回合：** `01-C251-edit`。

**操作顺序：**

1. 鼠标移到右侧“源 JSON”，查看只读源文件；点“定位当前问题”，展示动作第 4 题在完整文件中的位置。
2. 固定源文件侧栏，再切换一道题，观察定位随当前问题变化，随后取消固定、收起。
3. 在阶段选择框选择“复盘”，查看进攻复盘、防守复盘和改进建议三道题。展示第 1 题下方多个人物的 Excel 参考。

**预期看到：** 右侧展示完整源文件并高亮当前问题，源文件保持只读。C251 的 3 道复盘题排在 18 道阶段题之后，全部计入 21 题进度。

**可以这样说：**

> 需要核对原始上下文时，侧边可以直接查看完整源 JSON，并定位到当前问题。阶段题之后还保留了进攻、防守和改进建议三道复盘题。

### 6 精确对照 点击跳题与恢复 约 90 秒

**回合：** `01-C251-edit`。

**操作顺序：**

1. 按 `+` 打开“保存前核对修改”。
2. 指出按题汇总的导航，以及动作第 4 题答案中的红色删除、绿色新增和“替换”明细。
3. 点这条改动的“定位并编辑”，回到动作第 4 题。退出答案编辑后，点“本题改动”，再次核对局部差异。
4. 按 `Esc` 返回，点击顶部“恢复源 JSON”，观察本题改动消失；再点同一位置的“撤销恢复”，找回刚才的编辑。
5. 再按 `+` 查看完整对照，停一下让观众看清内容，再按一次 `+` 确认保存。

**预期看到：** 修改具体到词句，新增、删除和替换都能辨认。改动卡片可以返回对应题目继续编辑。恢复源作用于整个回合，确认保存前只改变页面内容；继续进行新编辑会结束这次“撤销恢复”的入口。保存后同目录出现一个 `qa-new.json`，源 `qa.json` 保留，并自动进入下一回合。

**可以这样说：**

> 保存前先看改了哪些词。发现需要重看，点题目就能回去；改完还可以只看本题差异。整个回合也能恢复成源文件状态，并立即撤销恢复。最终确认后才写入新版。

### 7 无改动跳过与重复新版清理 约 60 秒

**回合：** `02-C251-clean`，随后自动进入 `03-C251-duplicate`。

**操作顺序：**

1. 在 `02-C251-clean` 保持答案不变，按 `+` 打开对照，指出“0 处字段改动”和“无改动，下一回合”。
2. 再按 `+` 继续，在文件管理器中简要展示该目录没有 `qa-new.json`。
3. 进入 `03-C251-duplicate` 后，页面会提示已有新版与源内容相同。指出“保留已有新版”和“备份并删除重复新版”两个选择。
4. 在这个独立演示副本中点击“备份并删除重复新版”，展示源文件仍在、重复新版已清理、备份已留下。

**预期看到：** 与源内容一致时不会创建或覆盖新版；排版变化和对象字段顺序变化也不算标注修改。已有重复文件会单独询问，确认后先备份再清理。

**可以这样说：**

> 看过但没有修改的回合，直接继续，不额外生成新版。遇到之前留下的重复新版，会先比较，再由使用者决定保留或备份后清理。

### 8 磁盘旧版仍有改动时的处理 约 60 秒

**回合：** `04-C251-saved`。

**操作顺序：**

1. 用右侧下一回合按钮或 `】` 进入 `04-C251-saved`；也可从左侧列表直接选择。当前没有未保存编辑时，可用 `【` 返回上一回合。
2. 指出该回合已读入带“演示旧版修改”的新版，随后点击“恢复源 JSON”。
3. 按 `+` 查看当前内容与源文件一致，再按 `+` 进入“检查已有新版”。
4. 展示提示中的旧版差异：页面恢复了源内容，磁盘新版里的改动仍存在。现场可选择“保留已有新版，完成核对”；如需展示删除，只在这个独立演示副本中选择“备份并删除旧改动”。

**预期看到：** 系统会列出旧版相对源件的实际修改，再提供保留或备份后删除。确认期间文件被其他程序更新时，清理会停止并提示重新核对。

**可以这样说：**

> 页面恢复源内容之后，磁盘上以前保存的修改仍需要处理。这里先把那些旧修改列出来，让使用者看清内容，再决定是否保留。

### 9 展示结果与结束 约 30 秒

在文件管理器中展示 `01-C251-edit` 的 `qa.json` 和唯一的 `qa-new.json`，以及 `02-C251-clean` 只有源件的状态。备份结果按配置中的演示备份目录查看。

> 完整流程是：选回合，结合视频、图和人物记录逐题核对，编辑后检查具体差异，再确认保存。源文件始终保留；有修改才保留新版，已有冗余新版由使用者核对后处理。

## 3 分钟简版

| 时间 | 操作 | 要传达的重点 |
| --- | --- | --- |
| 0:00–0:30 | 打开 `01-C251-edit`，展开后收起文件列表，指向视频、图片、问答 | 单屏逐题核对 |
| 0:30–1:00 | 空格播放暂停，`J` 定位，`← / →` 微调，`X` 放大后 `Esc` 返回 | 迅速检查关键画面 |
| 1:00–1:30 | 第 1 题点其他选项再选回原答案；用 `Enter` 到第 3 题，看人名参考 | 选择题点击操作，Excel 辅助判断 |
| 1:30–2:00 | 第 4 题按 `Shift` 编辑一小处，再按 `Shift` 退出；悬停源 JSON | 编辑模式与源文件定位 |
| 2:00–2:30 | `+` 打开差异，展示红删绿增，点改动返回对应题，再打开对照确认保存 | 具体修改可核对、可回去继续编辑 |
| 2:30–3:00 | 在 `02-C251-clean` 连按两次 `+`，展示无改不生成新版；指出随后出现的重复新版提示 | 保存规则与人工确认清理 |

时间不足时，旧版仍有修改的清理场景留到提问环节；准备好 `04-C251-saved` 即可随时补演。

## 现场恢复方案

| 遇到的情况 | 处理方法 |
| --- | --- |
| 按空格或字母变成了输入文字 | 检查答案框是否高亮。单按 Shift 退出编辑；需要保持编辑时，用 Shift 加相应快捷键。其他输入框先点页面空白处退出输入。 |
| Enter 没有切题 | 先离开文本框、下拉框或弹窗，再按 Enter；也可直接点“下一题”。 |
| 字母键或数字小键盘反应不符 | 切到英文输入，检查 Num Lock；直接用页面按钮完成演示即可。 |
| 视频定位按钮不可用 | 等待视频就绪，并选择动作、战术或结果阶段。复盘题没有阶段截断点时，使用视频进度条回看。 |
| 人物参考为空 | 先选 C251 动作第 3 题或复盘第 1 题；检查同目录 Excel 是否存在。没有匹配人物时显示小龙属于正常状态。 |
| 图片或视频无法显示 | 回到事先验过的演示回合。检查演示文件是否完整；MOV 文件需要已配置的 FFmpeg（音视频处理工具），可优先使用准备好的 MP4 回合。 |
| 改多了或演示顺序乱了 | 暂停视频，按 Esc 关闭弹窗。先确认在演示地址，再用“恢复源 JSON”；需要找回刚才内容可立即“撤销恢复”。 |
| 切回合时提示未保存 | 选择取消，先回到“对照并保存”；演示副本中确实不需要的内容，确认后再放弃切换。 |
| 弹出文件已更新或清理失败 | 先返回编辑并保留当前内容，不反复确认。重新读取后核对版本；现场可先讲解界面中的保留选项，继续其他流程。 |
| 想重新演示第一次保存 | 不改正式数据。停止演示服务，把旧演示目录和配置改名留存，再重新运行准备脚本生成新副本。 |
| 现场无法连接服务器 | 使用已经准备并彩排过的本机演示页面，浏览和核对流程相同。 |

## 上台前速查卡

按这个顺序记忆即可：**选回合 → 播放定位 → 点选答案 → 看人物参考 → Shift 编辑 → 看源文件和复盘 → 对照跳题 → 恢复与撤销 → 确认保存 → 无改跳过 → 核对旧版后清理。**

- `Enter` 下一题，`Q / Backspace` 上一题，`【 / 】` 上下回合。
- 空格播放暂停，`A / J / D` 阶段前 2 秒、截断点、后 2 秒，`X` 放大图。
- `← / →` 前后 0.3 秒，`↑ / ↓` 调音量；数字小键盘兼容 `4 / 6 / 8 / 2`。
- 单按 `Shift` 进出答案编辑；编辑时按住 `Shift` 加快捷键。
- `+` 打开对照，再按一次确认保存或继续；清理提示中再次按 `+` 会确认备份并删除，讲解时先停下让观众看清选项。
