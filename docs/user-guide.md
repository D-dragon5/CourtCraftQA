# CourtCraftQA 使用教程

CourtCraftQA 将篮球回合视频、标注图片、问答和人物事件参考放在同一页，供人工逐题核对。核对时可修改答案、查看源文件和逐字差异，确认后把修改另存为同目录的 `qa-new.json`。原始 `qa.json` 保留。

现场介绍可按 [演示流程](demo-guide.md) 操作。日常核对建议依次完成“选回合 → 看视频与图片 → 核对题目 → 查看改动 → 确认保存”。

## 1 安装和启动

需要 Python 3.10 或以上版本，以及较新的桌面浏览器。后端和 Excel 读取均使用 Python 标准库，无须安装额外 Python 包，也无须安装 Microsoft Excel。

MP4、WebM、M4V 直接交给浏览器播放。MOV、MKV、AVI 会通过 FFmpeg 转为缓存视频，需要安装 FFmpeg，或在配置里填写可执行文件路径。浏览器仍需支持视频实际编码；文件扩展名本身不能保证可播放。

以 Windows 为例，将代码放在 `C:\CourtCraftQA`，数据放在独立的 `D:\basketball-data`：

```text
D:\basketball-data\
  C001\
    original.mp4
    action_boxes.jpg
    tactic_boxes.jpg
    outcome_boxes.jpg
    qa.json
    source_PL_label.xlsx
  C002\
    original.mov
    qa.json
    ...
```

程序会递归查找数据目录里的视频，并读取视频同目录的图片、JSON 和 Excel。每个回合使用独立文件夹最便于管理。Excel 文件名应为 `source_PL_label.xlsx`；缺少图片或人物表时，可继续核对已有问答。

在代码目录复制 `config.example.json` 为 `config.json`，按实际位置修改，例如：

```json
{
  "data_root": "D:/basketball-data",
  "host": "127.0.0.1",
  "port": 5012,
  "ffmpeg": "",
  "cache_dir": "cache",
  "backups_dir": "backups"
}
```

JSON 中的 Windows 路径可使用 `/`，或将每个反斜杠写成 `\\`。`data_root` 必须指向已经存在的数据根目录。`ffmpeg` 留空时自动查找项目的 `tools/ffmpeg.exe` 或系统 PATH，也可填系统命令名或完整路径，如 `C:/CourtCraftQA/tools/ffmpeg.exe`。相对目录按项目所在位置解析。

双击 `start.bat` 启动，浏览器会打开配置的端口；按上例访问 `http://127.0.0.1:5012`。关闭页面后，服务可以继续运行；双击 `stop.bat` 关闭本项目的 Python 服务。

也可在终端启动，便于查看错误：

```powershell
cd C:\CourtCraftQA
python token_viewer.py --config config.json
```

Linux 对应使用：

```sh
python3 token_viewer.py --config config.json
```

配置文件中的端口决定实际访问地址。若通过命令行或环境变量覆盖配置，以最终生效值为准；终端启动信息会显示数据目录和地址。

## 2 选择回合并熟悉页面

1. 将鼠标移到页面左边缘，或点击左上角菜单，展开回合列表。
   顶部“数据目录”可直接输入完整路径，点击“读取”或按 Enter 后立即切换并记住路径，无须手动修改配置或重启。输入当前服务所在电脑的目录：本机服务使用本机路径，服务器页面使用服务器上的路径。若有未保存编辑，会先询问是否放弃；无效目录不会改变当前回合。其他已打开的页面在目录不一致时会停止保存和清理，重新读取后再继续。
   列表上方显示当前实际读取的目录、回合目录总数和视频总数。程序递归读取配置目录下全部回合，没有 50 个的数量上限；每页显示 40 个视频，空目录或不含支持视频的目录不会列为回合。若有 200 个含视频的回合目录，应全部进入索引。
2. 搜索回合名或使用筛选框，点击视频。列表默认移开后收起，点“固定”可保持展开。
   列表滚到底后，连续向下滚轮两次可翻到下一页；第一次下滚会提示再滚一次。翻页只浏览文件列表，当前题目和未保存的答案保持不变。也可使用“上一页”“下一页”按钮。新增回合后点“刷新列表”，会立即重新扫描目录。
3. 左上查看视频，左下查看标注图；图上方可切换动作、战术、结果图片。右侧显示当前问题、答案及参考。
4. 有 `qa-new.json` 时优先读取已有新版；可在“更多 → 标注文件”切换文件，并在路径说明中确认读取和保存位置。

页面支持 `prediction` 中各阶段的 `qa`，以及独立的 `review` 复盘题。阶段下拉框可直接切换动作、战术、结果或复盘，题数和总进度取决于实际 JSON 内容。答案框按内容行数预留空间，较长内容可在输入框内滚动。

## 3 逐题核对和编辑

### 选择题

识别到按 A、B、C、D 等分行列出的选项时，页面会将其显示为可点击选项。原答案带有标记。点击其他选项即可修改；直接进入下一题会沿用当前答案。重新点击原答案选项可恢复源文件中的原答案值。

### 开放答案

单按一次 Shift，或点击答案框，进入答案编辑状态。答案框高亮，并提示“编辑答案状态，使用快捷键需摁住 Shift”。编辑结束后，再单按一次 Shift 退出。

编辑答案时，普通文字、空格、回车、Backspace 按输入框本身的行为处理。若要在编辑中切题或控制视频，按住 Shift 加对应快捷键，例如 Shift+Enter 下一题、Shift+J 跳到截断点。其他输入框、搜索框和弹窗有各自的输入行为，不能把所有按键都当作全局快捷键。

修改后的答案会在结束编辑、失去焦点、切题或打开对照前自动清除空格、换行、制表符等空白字符，包括英文词语或人名中间的空格。未修改的答案、精确恢复的原答案，以及读取后一直未改的已有新版答案，会保留原值。问题和其他标注字段不执行这项答案清理。

题目文字也可修改；选择题可先点击“编辑题目”。其他标注字段和完整 JSON 编辑入口位于“更多”。这些编辑会保留在当前回合页面中，确认保存后才写入新版文件。

## 4 视频 图片和人物参考

当前阶段有有效截断时间时，J 跳到截断点，A 跳到截断点前两秒，D 跳到截断点后两秒，跳转后立即播放。接近视频首尾时会限制在有效范围内。方向键左右是相对当前播放位置前后微调 0.3 秒，并保持原有播放或暂停状态。

X 放大当前实际显示的标注图。关闭图片弹窗后返回核对页。播放速度可在“更多”中选择。

程序根据当前问题和答案提到的人名，匹配同目录 Excel 的人物事件，在答案下面列出人物、原始时间标记、事件、结果、工作表及行号。可点击“展开记录”查看当前匹配到的完整记录。时间按表格原样展示，人物匹配和事件记录供人工判断使用。

人物表正常读取但当前问答未匹配到人物时，下方显示小龙与 `dddlong` 署名。Excel 缺失或读取失败时会显示对应提示。

## 5 查看源 JSON

将鼠标移到“源 JSON”按钮或页面右侧“源 JSON”边缘，展开只读侧栏。这里显示完整源文件，并高亮当前问题在文件中的位置。切题时会定位到相应问题；可点“定位当前问题”重新定位，或点“固定”保持侧栏展开。

这个侧栏只读。若当前加载的是 `qa-new.json`，对照仍以对应的原始 `qa.json` 为基准。源文件缺失时会明确提示，无法使用源文件恢复和源件差异比较。

## 6 核对改动并保存

点击顶部“对照并保存”，或在普通核对状态按 `+`，打开保存前核对页。

- 顶部按题目汇总有改动的位置；点击题目按钮或“定位并编辑”直接返回该题。
- 每张卡片给出题目背景、改动字段和字符数。红色删除线表示删除，绿色下划线表示新增；替换会列出旧内容到新内容。
- 空格显示为 `␠`，换行显示为 `↵`，连续空白可用数量表示，便于识别肉眼难发现的变化。
- 返回题目后，可点击“本题改动”再次核对该题；“查看全部改动”返回整回合清单。

确认无误后点击底部按钮，或再次按 `+`。有实际修改时，写入同目录 `qa-new.json`，随后进入当前筛选列表的下一回合；列表最后一回合显示完成。即使对照页当前只显示本题，保存也作用于整个回合。

每个源文件对应一个固定新版。例如 `qa.json` 对应 `qa-new.json`，后续更新继续使用它，不会生成 `qa-new-new.json`。更新已有新版前自动备份。所有修改都保留在页面中，点击“下一题”本身不会写盘。

### 没有修改时

程序按 JSON 内容比较，忽略缩进、排版和对象字段顺序。当前内容与源文件一致时，不创建或覆盖新版文件。

| 磁盘状态 | 页面处理 |
| --- | --- |
| 没有 `qa-new.json` | 显示无改动，直接进入下一回合或完成 |
| 已有新版与源文件内容相同 | 提示是否保留，或备份后删除重复新版 |
| 当前页面已恢复源内容，但已有新版仍有修改 | 先展示磁盘旧版与源文件的差异，再选择保留或备份后删除旧改动 |

删除提示中再次按 `+` 等于确认“备份并删除”，请先看清提示内容。选择“保留已有新版”不会改写或删除该文件；按 Esc 返回编辑也不会删除。程序不会因为当前页面没有改动就静默移除已有标注。

## 7 恢复源内容和找回备份

“恢复源 JSON”位于上下回合按钮旁，会把整个回合恢复为源文件内容。此时只改变页面，还未改磁盘。可点击“撤销恢复”找回恢复前的编辑；继续作新编辑后，这个单步撤销入口会结束。

恢复后点击对照，可以看到当前相对源件已无改动。若磁盘存在旧版，仍需按上一节流程决定保留或备份后删除。

默认备份目录是项目下的 `backups`，按数据根目录内的相对文件路径分层，例如：

```text
backups/C001/qa-new.json/时间戳-随机标记.bak
```

需要手工找回时，先停止编辑并另存当前页面内容，再确认相应回合及备份时间。把需要的 `.bak` 复制为独立的检查用 `.json`，打开核对内容；确认后再恢复为该回合的 `qa-new.json`。恢复前保留当前新版副本，勿覆盖原始 `qa.json`。若备份目录配置到另一磁盘，清理过程还可能在回合目录保留隐藏的 `.viewer-cleanup-*.bak`；出现恢复副本提示时保留提示所指文件。

保存或清理前会核验读取版本、源文件版本和新版版本。如果文件已被其他窗口或程序修改，操作会停止，并保留当前编辑。此时先把当前 JSON 内容复制到独立文件，再重新读取、核对并合并需要保留的修改。缺少源文件时，已有新版仍可编辑保存，但不会提供依据源件的自动清理入口。

## 8 快捷键速查

下表用于普通核对状态。答案编辑状态下，按住 Shift 加相应按键才能触发操作。

| 按键 | 操作 |
| --- | --- |
| Enter | 下一题；最后一题打开对照 |
| Q 或 Backspace | 上一题 |
| 【 / 】，兼容英文 [ / ] | 上一回合 / 下一回合 |
| 空格 | 视频播放 / 暂停 |
| J | 跳到当前阶段截断点并播放 |
| A / D | 跳到截断点前 / 后两秒并播放 |
| ← / →，小键盘 4 / 6 | 相对当前时间前后微调 0.3 秒 |
| ↑ / ↓，小键盘 8 / 2 | 音量增加 / 减少 5% |
| X | 放大当前标注图 |
| +，含小键盘加号 | 打开对照；对照中确认保存或跳过无改回合；清理提示中确认备份删除 |
| Shift 单按 | 进入 / 退出答案编辑状态 |
| Esc | 关闭当前弹窗或返回编辑 |

按钮上也标有相应快捷键。输入法正在组字、按住 Ctrl/Alt/系统键或处于其他输入框时，快捷键可能不会触发；此时可直接点击按钮。

## 9 本机和服务器使用

本机模式中，服务在本机运行，读取本机配置的数据目录。服务器模式中，服务和读写操作都在服务器；通过 SSH 端口转发后，可在自己的电脑浏览器查看和操作。网页显示在电脑上，并不意味着读写的是电脑里的数据。

两边若使用独立数据副本，标注结果不会自动同步。开始核对前确认入口地址和“更多”里的文件路径，避免在错误副本上继续编辑。需要同步结果时，应先比较双方源文件和新版，保留备份后再复制，避免直接覆盖不同的人工修改。

## 10 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 启动提示数据目录不存在 | 检查 `config.json` 中的 `data_root`，并确认当前盘符或挂载路径可用 |
| 页面打不开 | 确认服务已启动，访问端口与配置一致；在终端启动查看错误 |
| 端口已被其他程序使用 | 为本项目配置空闲端口，并使用新地址访问；不要关闭用途不明的程序 |
| 找不到视频或新回合 | 确认视频在数据根目录内，点击列表“刷新”；目录索引可能短暂缓存 |
| 视频首次打开较慢 | MOV 等格式首次需要转码；等待缓存生成，检查 FFmpeg 配置和磁盘空间 |
| MP4 仍无法播放 | 检查视频实际编码，可先转为浏览器支持的 H.264/AAC MP4，再放入回合目录 |
| 截断点按钮不可用 | 当前阶段缺少有效截断时间，或视频尚未加载；复盘题不一定有截断时间 |
| 人物参考为空或报错 | 检查同目录 `source_PL_label.xlsx` 文件名、人物列和时间事件记录；表格只读，不会被程序修改 |
| 键盘按了没有反应 | 先看是否处于答案编辑状态；退出编辑，或按住 Shift 加快捷键；也可直接点按钮 |
| 保存提示文件已改变 | 保留当前编辑内容，再重新读取并人工合并；避免用旧页面继续覆盖 |
| 提示页面验证过期 | 先将未保存的完整 JSON 复制到独立文件，再刷新并重新核对 |
| 切回合时出现未保存提示 | 需要保留修改时先取消切换并完成对照保存；确认放弃才切换 |

现场演示建议使用独立复制的数据和配置：运行 `python scripts/prepare_demo.py "D:\basketball-data\C251"`，生成编辑、无改动、重复新版、旧版已有修改四个独立场景，再运行 `python token_viewer.py --config demo-config.json`，或双击 `start-demo.bat`。演示地址为 `http://127.0.0.1:5016`，结束后使用 `stop-demo.bat` 关闭。脚本拒绝覆盖已有演示目录或配置，重新准备时指定新的 `--output` 和 `--config`。按 [演示流程](demo-guide.md) 提前跑一遍完整保存流程。
