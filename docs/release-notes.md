# 0.2.0

Windows 完整便携包内置 Python 和 FFmpeg，全部解压后即可运行。

- 新增 `install-shortcuts.bat`，在桌面创建启动、查看状态、停止三个入口；无需管理员权限。移动解压目录后，在新位置重新创建快捷方式。
- 新增 `status.bat`，显示服务是否运行、地址、当前数据目录和日志位置。关闭浏览器后，后台服务继续运行，使用停止入口结束。
- 动作、战术、结果阶段各有 6 题时，同页配对显示 1＋4、2＋5、3＋6；复盘及其他题数保持逐题。
- Tab 编辑第一个答案，单按 Shift 编辑第二个答案；先 Tab 后 Shift 直接切换，同键再按退出。单题页两键都编辑唯一答案。编辑中按住 Shift 使用原快捷键。
- 可拖动左右区域、视频与图片、上下两组问答之间的分隔线。切页时问答按内容自动分配高度，空间不足先压缩底部参考区。顶部新增“全屏（F11）”。
- 答案清理保留英文词语和姓名之间的空格；图片显示 JSON 中对应时间；保存前可逐字对照并点击跳回题目。

压缩包不包含比赛视频、真实标注、人物表、实际配置、日志或备份。原始 `qa.json` 保留，修改保存为同目录唯一的 `qa-new.json`。

旧版升级建议解压到新目录，保留旧目录，再在网页侧栏选择原数据目录。新旧版本共用数据时，先停止旧服务，避免同时编辑同一文件；备份仍留在创建它们的项目目录中。

最简流程与环境说明见 [Windows 快速使用](quick-start.md)，详细操作见 [使用教程](user-guide.md)。
